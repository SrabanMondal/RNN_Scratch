# RNN_Scratch
<b>Single-Layer RNN with Dynamic Weights</b> – Built a single-layer Recurrent Neural Network (RNN) from scratch based on a research paper and its proposed formula. Implemented dynamic weights to optimize learning and incorporated Backpropagation Through Time (BPTT) for efficient training. The model captures temporal dependencies in sequential data, showcasing deep understanding of RNNs, weight updating, and gradient propagation.
